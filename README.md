OutBot is a discord bot created by mythordian and aardappel1. OutBot was created for the Discord Server OutMyth. Which mythordian partially owns. OutBot is open source; continas 16 slash commands. OutBot uses "w" mode logging. Logging is only there to fix crashes and errors. OutBot uses NO privileged intents as it doesn't need to. OutBot only has no prefix commands or command prefixes. OutBot uses an .env file to ensure OutBot's Discord Token doesn't get leaked.
